# Deep Learning-Based Energy Forecasting with Transfer Learning

This project presents a deep learning framework for accurate time-series forecasting of energy demand and consumption patterns across multiple datasets. It combines signal processing techniques, including Empirical Mode Decomposition (EMD) and Discrete Wavelet Transform (DWT), with Particle Swarm Optimization (PSO)-based clustering and a hybrid CNN-Transformer architecture. A transfer learning strategy is employed through a reusable pretrained encoder and a two-stage training procedure, enabling knowledge transfer across different datasets and forecasting tasks. The framework is evaluated using standard regression metrics, including MAE, MSE, RMSE, and R². Experimental results demonstrate promising predictive performance, achieving an R² score of **0.980 on one of the evaluated electricity forecasting datasets** and **0.940 on another forecasting task**. By integrating temporal feature extraction, noise reduction, adaptive clustering, and attention-based sequence modeling, this project provides a flexible and scalable approach to energy time-series forecasting, with potential applications in smart grids, energy management, and consumption prediction.
